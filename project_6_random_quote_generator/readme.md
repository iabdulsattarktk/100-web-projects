# Project 6/100 - Random Quote Generator

## What this project does
A web app that fetches random inspirational quotes from an API and displays them on screen.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Type.fit Quotes API

## Features
- Fetches random quotes from a free API
- Displays quote text and author name
- "New Quote" button loads a fresh quote
- Fully responsive design

## What I learned
- How to use the Fetch API
- What JSON data is and how to use it
- How CORS works
- Connecting JavaScript with HTML elements using getElementById
- Using Math.random() to pick random items from an array
