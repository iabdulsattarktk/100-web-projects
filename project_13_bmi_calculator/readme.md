# Project 13: BMI Calculator

## Description
Simple BMI (Body Mass Index) calculator jo weight aur height 
lekar user ka BMI calculate karta hai aur category batata hai 
(Underweight, Normal, Overweight, Obese).

## Features
- Weight (kg) aur height (cm) input
- BMI formula: weight / (height in meters)²
- Input validation (empty/invalid values check karta hai)
- Category ke sath result display

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
