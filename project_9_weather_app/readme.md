# Weather App

A simple and elegant weather application built with HTML, CSS, and JavaScript. It lets users search for a city and view its current weather details, including temperature, description, humidity, and wind speed.

## Features

- Search weather by city name
- Display current temperature in Celsius
- Show weather description
- Show humidity and wind speed
- Responsive and clean UI

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Project Structure

- index.html - Main page structure
- style.css - Styling for the app
- script.js - Weather search logic and API integration

## How to Run

1. Open the project folder in your browser.
2. Double-click index.html, or use a live server extension in VS Code.
3. Enter a city name and click Search.

## API Setup

This app uses the OpenWeatherMap API.

- Replace the API key in script.js with your own key if needed.
- You can get a free API key from: https://openweathermap.org/api

## Notes

- Internet access is required to fetch weather data.
- Make sure the city name is entered correctly for accurate results.
