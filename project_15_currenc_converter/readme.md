# Project 15: Currency Converter

Simple currency converter jo live exchange rates use karta hai.

## Features
- FROM aur TO currency select kar sakte hain (USD, GBP, SAR, PKR)
- Amount enter karke live rate se conversion
- Swap button se FROM/TO switch kar sakte hain

## Tech Stack
- HTML
- CSS
- JavaScript (vanilla)

## API Used
- [Frankfurter API](https://www.frankfurter.app/) — free, no API key required
