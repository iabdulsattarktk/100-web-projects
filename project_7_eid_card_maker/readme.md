# Project 07 — Eid Card Maker

## Description
Ek interactive Eid card maker jisme user apna naam, message, aur theme choose karke card banata hai aur PNG format mein download karta hai.

## Features
- Live card preview — naam aur message real-time update hota hai
- 3 themes — Green, Gold, Blue
- Arabic "عید مبارک" text with Amiri font
- Card PNG download (html2canvas library)

## Tech Stack
| Technology | Use | <br>
|---|---| <br>
| HTML5 | Page structure | <br>
| CSS3 | Styling + themes | <br>
| Vanilla JavaScript | Live preview + download logic | <br>
| html2canvas | Card ko image mein convert karna | <br>
| Google Fonts | Amiri + Poppins fonts | <br>

## Concepts Learned
- DOM manipulation — `getElementById`, `querySelector`
- Event listeners — `input`, `change`, `click`
- CSS classes dynamically add/remove karna — `classList.add`, `classList.remove`
- CDN se library use karna
- `html2canvas` se HTML element download karna
- CSS `linear-gradient` for themes
- Flexbox layout
- Google Fonts embed karna + weights select karna
- Radio buttons custom styling
- CSS transitions
