# Project 11: To-Do List (with localStorage)

## Description

Ek simple to-do list app jisme user tasks add, complete, aur delete kar sakta hai. Tasks browser ke localStorage mein save hote hain — matlab page refresh ya close karne ke baad bhi tasks wahi rehte hain.

## Features

- Naya task add karna
- Task pe click karke usse "completed" mark karna (line-through style)
- Task ko delete karna
- Tasks localStorage mein persist hote hain (refresh ke baad bhi maujood rehte hain)

## Tech Stack

- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla) — DOM manipulation, localStorage API

## What I Learned

- localStorage.setItem() aur localStorage.getItem() ka use
- JSON.stringify() aur JSON.parse() ka data convert karne ke liye
- Dynamic DOM elements create karna (createElement, appendChild)
- Event delegation / event listeners on dynamically created elements

## How to Run

1. Repo clone karo
2. `project-11-todo-list` folder open karo
3. `index.html` browser mein open karo
