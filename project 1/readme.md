# HTML & CSS Project 12 - Tribute Page

This project is a simple tribute webpage built with HTML and CSS. It showcases a profile-style layout for Dr. Abdul Qadeer Khan with sections for introduction, biography, and a footer.

## Features
- Clean and centered layout
- Responsive page structure
- Styled heading, image, biography list, and footer
- Use of simple CSS for spacing, colors, and typography

## Project Structure
- index.html: Main HTML structure of the page
- style.css: Styling for the layout and content
- images/: Folder containing project images

## How to Run
1. Open the project folder in your browser.
2. Double-click the index.html file, or use a live server if available.

- HTML
- CSS
